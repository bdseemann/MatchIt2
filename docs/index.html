Installing on your phone

  1. Open this page in your phone's browser and tap the download button above.
  2. Open the downloaded file from your notifications or Downloads app.
  3. Android will ask to allow installing from this source the first time — allow it.
  4. Tap Install.

This is a debug-signed APK, not distributed through the Play Store, so Android shows a warning before installing — that's expected for a sideloaded app like this one.
